- **网关应用控制**
  - config type
    |         config type          | value |
    | :--------------------------: | :---: |
    |  reload plugin node config   |   0   |
    | reload plugin node subdevice |   1   |
    |      start plugin node       |   2   |
    |       stop plugin node       |   3   |
    |     restart plugin node      |   4   |
  - **请求网关应用重新加载配置**
    - 请求
      - 请求Topic: `wan/${parentThingProductKey}/${parentThingDeviceName}/thing/pluginNode/config/push`
      - 请求数据格式
        ```json
          {
              "id": "123",
              "transId": "requestTransId",
              "version": "1.0",
              "params": {
                  "configType": 0,
                  "deviceIotId": "string",
                  "pluginNodes": ["pluginNodeId1","pluginNodeId2"]
              },
              "method": "thing.pluginNode.config.push"
          }
        ```
    - 响应
      - 响应Topic: `wan/${parentThingProductKey}/${parentThingDeviceName}/thing/pluginNode/config/pushReply`
      - result type
        | result type |   value    |
        | :---------: | :--------: |
        |     -2      | 应用不存在  |
        |     -1      |    失败    |
        |      0      |    成功    |
        
      - 响应数据格式
        ```json
        {
            "id": "123",
            "transId": "requestTransId",
            "code": 200,
            "data": {
              "configType": 0,
              "deviceIotId": "string",
              "pluginNodesResults": [
                  {
                      "pluginNodeId": "string",
                      "result": 0
                  }
              ],
              "method": "thing.pluginNode.config.pushReply"
            }
        }
        ```
